01ETIQUETADORZPL / VISION

Automatizacion de impresion para deposito

EtiquetadorZPL con flujo Odoo + etiquetas

Plataforma local para recibir archivos, convertir a ZPL, enviar a impresoras y controlar todo desde GUI y dashboard web.

02POR QUE EXISTE

Valor operativo inmediato

  • Procesa PDF, ZPL, TXT y ZIP automaticamente desde carpetas monitoreadas.
  • Hasta 3 flujos paralelos con impresora, historial y copias por carpeta.
  • Reduce trabajo manual y errores de operador en deposito.
  • Muestra estado, logs y metricas en dashboard web y GUI.
  • Integra orden Odoo + etiqueta de envio en un circuito unico.
03MODULOS

Arquitectura modular orientada a operacion

API FastAPI

Estado, acciones y configuraciones para web y automatizaciones.

Servicio monitor

Observa carpetas de entrada y dispara impresiones continuas.

GUI local

Setup rapido de carpetas, impresoras, historial y copias.

Dashboard web

Visibilidad de trabajos, metricas y mantenimiento remoto por LAN.

Integracion Odoo

XML-RPC + descarga PDF de ordenes con manejo de errores.

Worker Odoo

Sincroniza envios y ejecuta orden + etiqueta con fallback.

04INTEGRACION ODOO

Capacidades implementadas en codigo

  • Autenticacion XML-RPC contra /xmlrpc/2/common y /xmlrpc/2/object.
  • Busqueda de sale.order por envio, prefijo y estados permitidos.
  • Descarga de PDF de orden via sesion web autenticada.
  • Confirmacion de orden (action_confirm) con verificacion before/after.
  • Impresion con verificacion de spooler, timeout y timeline de etapas.
05ROBUSTEZ

Confiabilidad y operacion diaria

  • Mensajes de error humanizados para XML-RPC y base de datos Odoo.
  • Enmascarado de credenciales y configuracion segura publicada.
  • Worker con memoria de envios procesados para evitar duplicados.
  • Backups, logs, notificaciones y metricas de rendimiento desde dashboard.
  • Roadmap 1.1: constants/exceptions/utils/rate-limiter/circuit-breaker.
